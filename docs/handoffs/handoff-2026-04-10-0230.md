## Decisions

- **Activity tab device resolution**: Auto-selects the first device from `DevicesRepository.getDevices()`. Once the backend supports cross-device queries, this can be updated.
- **Focus mode auto-end**: Mapped to `durationMinutes` — "off" sends default 60 min, "1h/2h/4h" sends explicit duration. Backend already handles timer expiry.
- **Stats endpoint**: Lives on `DevicesController` (not scheduler) since it queries across multiple entity types. Returns aggregate counts only — no time-series yet.
- **Tone presets**: Changed from free-text to 5 radio options (Professional, Friendly, Playful, Sarcastic, Custom). "Custom" reveals a text field.
- **System prompt**: Moved under an `ExpansionTile` "Advanced" section — most users won't touch it.
- **Color pickers for display**: Simple palette dialog with 9 color options instead of a full color picker widget. Keeps dependencies minimal.
