## Decisions made

- **VAD replaces touch-release**: audio capture loop checks VAD first, auto-stops after 1.5s silence. Touch hold_end still works as manual override.
- **Power management integrates with presence**: AWAY → display sleep, PRESENT → display wake. Idle timeout also dims/sleeps independently.
- **Display is 3-layer architecture**: face (state machine) → display (mode manager) → display_hw (TFT driver). Only display_hw needs hardware.
- **Debug logging replaces Serial.printf**: LOG_I/W/E macros, rolling file on SD. Existing Serial.printf calls should be migrated when hardware is ready.
- **OTA is download-first**: firmware.bin downloads to SD and verifies SHA-256 before any flash attempt. Safe to test download/verify without bricking risk.
