## Decisions

- **Raw `ws` over Socket.IO** — ESP32's `esp_websocket_client` speaks standard WebSocket, not Socket.IO protocol. Using `@nestjs/platform-ws`.
- **`core/` + `modules/` structure** — Hendra wanted scalability for 7+ modules. Infrastructure (config, database, common) lives in `core/`, feature modules in `modules/`.
- **ConversationPersistence extracted** — Gateway was growing. DB operations moved to a dedicated service to keep the gateway focused on protocol handling (SRP).
- **Memories stub** — getRelevant() returns empty array, bumpAccessed() is no-op. Full implementation in Phase 3.
- **Redis port 6380** — Port 6379 was already in use on Hendra's machine. docker-compose maps 6380:6379.
- **`as any` cast on JWT expiresIn** — @nestjs/jwt v11 uses jsonwebtoken's strict `StringValue` type which doesn't accept `string` from ConfigService. Cast is the pragmatic fix.
- **TypeORM baseUrl removed** — Deprecated in TS 7.0, not needed since all imports are relative.
