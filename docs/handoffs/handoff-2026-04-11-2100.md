### Key decisions

- **BLE + WiFi can't coexist** on ESP32-S3 — crashes. BLE only runs during provisioning (before WiFi). Skipped entirely on normal boot.
- **WiFi init must happen early** — before display sprite, audio DMA, Opus codec. Otherwise internal SRAM runs out and WiFi can't allocate RX buffers.
- **Echo buffer allocated lazily** — 500 frames × 320 samples × 2 channels × 2 bytes = 640KB PSRAM. Only allocated on first hold-to-talk.
- **Touch Y-axis inverted** — `tapY = (LCD_HEIGHT - 1) - tp.y` in BIOS menu touch reading.
- **Smart quote in iPhone SSID** — "Hendra's iPhone" uses Unicode right single quotation mark (U+2019), not ASCII apostrophe. Currently using Poco hotspot instead.
- **LovyanGFX test pattern removed** — was drawing "LovyanGFX OK" text + diagonal lines during display init.
- **No connecting screen on normal boot** — face shows immediately, WiFi connects silently in background.
