**Session: Idle personality, settings fixes, presence detection, memory extraction, UI overhaul**

## Status

**Idle personality chat: IMPLEMENTED.** Backend ProactiveService fires random Gemini quips at configurable intervals (rare/normal/frequent). App has Personality settings page with Save button. Firmware idle animation speed configurable via `face::setIdleInterval()`.

**Personality customization: REMOVED.** Bot name hardcoded to "Aksa", gen-z personality embedded in system prompt with identity context (desk companion, built by Hendra, push-to-talk, no camera). Removed GET/PATCH personality endpoints, Personality tab, BLoC event, datasource/repository methods.

**Memory extraction: IMPROVED.** Added empty response detection (Gemini safety filter), JSON array extraction from preamble text, better logging throughout pipeline. Added `POST /devices/:id/memories/extract-latest` diagnostic endpoint. Still needs real-world verification — may need Dokploy log checking.

**Device settings: FIXED.** Key mismatches resolved (`showTranscript` → `display_transcript`, `idleTimeoutMinutes` → `idle_timeout_seconds`). Device name removed from settings (not a setting). All new keys added to DTO (`idle_chat_enabled`, `idle_chat_frequency`, `idle_animation_speed`, `audio_jitter_ms`, `presence_enabled`). Settings extracted to standalone page.

**Presence detection: FIXED.** UUID format crash fixed (short `ffe4` → full 128-bit). BLE state monitoring added. Permission dialog with error details. Runtime enable/disable via `config:update` to ESP32. `Reply already submitted` crash fixed by not calling start/stop in state listener.

**Reminders: FIXED.** Work hours enforcement added. Type mismatch fixed (`eyeBreak` → `eye_break`). Duration sent flat (not nested in display object).

**Audio: IMPROVED.** Jitter buffer 200ms → 300ms (configurable via `audio_jitter_ms`). Runtime volume control via `audio_io::setVolume()`. Volume reads NVS on boot instead of hardcoded 70%.

**Display wake: FIXED.** `display::wake()` was setting `brightness = userBrightness` before calling `fadeBrightness()`, causing the fade to be skipped (target == current). Touch-to-wake now works.

**App: FIXED.** Auth page flash eliminated (`initialLocation` → `/home`). API client crash on non-JSON errors fixed. Conversation cards show preview + message count.

### What was done this session

#### 1. Idle personality animations
- Backend `ProactiveService`: per-device idle chat timer with configurable frequency (rare=15-25min, normal=8-15min, frequent=3-8min)
- 6 prompt categories: fun fact, time comment, random thought, user roast, encouragement, desk life observation
- `sendIdleChatAudio()` in AudioGateway: face expression + TTS audio delivery
- Timer pauses during conversation, resumes when idle
- Firmware: `face::setIdleInterval(minMs, rangeMs)` for configurable animation speed
- App: `IdlePersonalityPage` with Save button pattern (no auto-save)

#### 2. Personality removal
- Hardcoded `BOT_NAME = 'Aksa'` and `SYSTEM_PROMPT` in `prompt.service.ts`
- System prompt includes bot identity (name, physical description, limitations, creator)
- Removed `PersonalityConfig` interface, `getPersonality()`/`updatePersonality()` from service/controller
- Removed `_PersonalityTab`, `UpdatePersonality` BLoC event, datasource/repository personality methods
- Updated all proactive service prompts to use `BOT_NAME`

#### 3. Memory extraction fixes
- `MemoryExtractorService`: empty response detection, JSON array extraction from preamble text, per-extraction logging
- `MemoriesService`: added logging for message count, extraction result
- `extractFromLatestConversation()` diagnostic method + REST endpoint
- Added `Conversation` repo to memories module

#### 4. Device settings overhaul
- Fixed key mismatches: `showTranscript` → `display_transcript`, `idleTimeoutMinutes` → `idle_timeout_seconds`
- Removed `name` from settings patch (was causing DTO validation failure)
- Added to `UpdateSettingsDto`: `idle_chat_enabled`, `idle_chat_frequency`, `idle_animation_speed`, `audio_jitter_ms`, `presence_enabled`
- All settings pages now send only changed keys (not full snapshot) to avoid `forbidNonWhitelisted` validation errors
- Extracted settings to `DeviceSettingsPage` (standalone, no tabs)
- Device detail page: removed tabs, compact status bar, quick actions only

#### 5. Presence detection fixes
- Fixed UUID: `Guid.str` returns short `ffe4`, Android needs full `0000ffe4-0000-1000-8000-00805f9b34fb`
- Added `lastError` to `BlePresenceService` for diagnostics
- Permission dialog shows specific failure reason
- BLE state listener updates UI only (no start/stop to avoid plugin crash)
- Firmware: `config:update` handles `presence_enabled` for runtime BLE scan start/stop
- `startAdvertising()` requests permission first, handles all state codes

#### 6. Reminder fixes
- Work hours enforcement: reads `workHoursStart`/`workHoursEnd` from device settings
- Fixed type mismatch: firmware checks `eye_break` (snake_case) matching backend
- Duration sent flat at top level (not nested in `display`)
- Added `workHoursStart`/`workHoursEnd` to `ReminderConfig` type

#### 7. Audio improvements
- Jitter buffer: 200ms → 300ms (15 frames), configurable via `audio_jitter_ms` setting
- `audio_io::setVolume()`: runtime ES8311 codec volume control with perceptual curve
- `init()` reads volume from NVS instead of hardcoded 70%
- `config:update` handler calls `audio_io::setVolume()` on volume change

#### 8. Display wake fix
- `display::wake()`: removed premature `brightness = userBrightness` before `fadeBrightness()` call
- `fadeBrightness()` guard `target == brightness` was skipping the fade, leaving backlight at 0
- Touch WAKE event now resets `botState` to IDLE and syncs face

#### 9. App fixes
- Auth flash: `initialLocation` changed from `/login` to `/home`
- API client: `_mapException` handles non-JSON responses (string/HTML)
- Conversation cards: preview text + message count from backend
- ArduinoWebsockets patches: pre-build script in `firmware/patches/apply_patches.py`
