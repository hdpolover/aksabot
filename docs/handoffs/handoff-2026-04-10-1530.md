**Session: Hardware integration — ESP32 ES3C28P board**

## Status

The ESP32 board (ES3C28P) is **flashed and running** with display, touch, audio codec, Wi-Fi, and WebSocket all initialized.

### What's working
- **Display**: ILI9341V 240x320, sprite-buffered face rendering at 30fps, custom bitmap font for text (TFT_eSPI text broken on this board)
- **Touch**: FT6336G capacitive, I2C polling, hold/tap/long-press events
- **Audio**: ES8311 codec initialized via I2C, I2S full-duplex (mic + speaker)
- **Wi-Fi**: connects to hotspot (2.4GHz only), IP assigned
- **WebSocket**: connects to backend, sends/receives events
- **Status bar**: WiFi/WS indicators visible with bitmap font
- **State labels**: "Ready", "Hold to talk" at bottom
- **Power management**: auto-dim after 30s, sleep after 5min, wake on touch
- **NVS, Opus, VAD, presence detector**: all initialized

### What needs work next session
1. **Test voice round-trip**: hold screen → record → send to backend → get response → play through speaker. Audio I/O is initialized but untested with real speech.
2. **Fix WebSocket stability**: WS occasionally disconnects during audio streaming. May need larger WS task stack or slower chunk rate.
3. **SD card**: SDIO init fails with no card inserted. Need to test with a MicroSD card.
4. **Touch sensitivity**: FT6336G sometimes triggers multiple events. May need tuning of debounce or I2C polling rate.
5. **Face polish**: smile curve, eye proportions, expression transitions could be refined.
6. **BLE GATT server**: for provisioning via Flutter app (currently using compile-time credentials).

### Key hardware findings
- **Board model**: ES3C28P (not Waveshare, not Sunton — generic Chinese board)
- **PSRAM type**: `dio_opi` (not `qio_opi` — board crashed with wrong type)
- **Partition table**: must use `default_16MB.csv` (custom partitions.csv caused boot loop)
- **TFT_eSPI text**: completely broken on this board's SPI config. Shapes work fine. Used custom `bitmap_font.h` (5x7 pixel font drawn with fillRect) as workaround.
- **I2C shared bus**: touch (FT6336G) and audio codec (ES8311) share GPIO 15/16. Touch initializes Wire first; audio skips i2c_driver_install if already running.
- **Pin comment mismatch**: the `.ino` file comment says DC=2, BL=21 but the actual `spi_dev.h` defines say DC=46, BL=45. Always trust the #defines, not comments.
- **Color inversion**: ILI9341V on this board shows correct colors with `TFT_BLACK`/`TFT_WHITE` as-is (no invertDisplay needed).
