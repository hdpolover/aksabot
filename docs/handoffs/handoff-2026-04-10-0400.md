## Decisions

- **Device claim vs create**: Add Device Wi-Fi flow uses `POST /devices/claim` (looks up existing device by token) instead of creating duplicates. BLE flow uses `POST /devices` (creates new device, writes token to ESP32).
- **BLE GATT UUIDs**: Using 128-bit UUIDs with base `0000xxxx-0000-1000-8000-00805f9b34fb` where xxxx maps to service/characteristic numbers from the spec.
- **BLE provisioning auto-register**: Step 3 auto-starts registration when the page becomes visible. No user action needed — just an animated checklist showing progress.
- **Duration formatting**: `420m 30s` → `7h 0m` when duration exceeds 1 hour. Uses hours+minutes for long durations, minutes+seconds for short ones.
- **Device info uptime**: Calculated from `lastSeenAt` when device is online. Wi-Fi signal and firmware version show "Requires BLE" since they need hardware connection.
