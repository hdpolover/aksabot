## Decisions

- **ElevenLabs over Google Cloud TTS** — Much better voice quality and expressiveness. Using Ziggy voice (community, young energetic boy) with stability 0.6, style 0.3, speed 0.8x. Google TTS adapter kept as fallback.
- **`opusscript` over `@discordjs/opus`** — Native bindings segfault on macOS after 1-2 encodes. opusscript is pure JS (WASM), stable. ESP32 uses native libopus.
- **Opus frame format** — TTS audio encoded as `[len16BE][opus_frame]...` with 2-byte big-endian length prefix per frame. ESP32 reads length, extracts frame, decodes.
- **Lazy response pool** — Pool entries generate on first reminder fire (batch of 5), not on connect. Background refill every 6h. Avoids draining Gemini budget on reconnects.
- **Time-aware greeting** — Bot checks hour and greets appropriately (morning/afternoon/evening/night), not always "good morning."
- **Uncommon ports** — NestJS: 4280, PostgreSQL: 5489, Redis: 6312.
- **Flutter clean architecture** — feature-based folders with data/domain/presentation layers. BLoC for state, GoRouter for nav, GetIt for DI, Dio for HTTP.
- **FVM** — Flutter 3.41.6, pinned via `.fvmrc`.

## Bugs found and fixed

| Bug | Root cause | Fix |
|-----|-----------|-----|
| `@discordjs/opus` segfault | Native binding crash on macOS | Swapped to `opusscript` |
| Opus encode "out of bounds" | Full TTS buffer as single frame | Frame-by-frame with length prefix |
| Google STT "Malordered Data" | PCM wrapped in `{audioContent}` | Write raw PCM to stream |
| Gemini 400 Bad Request | `systemInstruction` as string | Wrap in `{role, parts}` Content |
| Dropped `audio:start` events | Message handler after async setup | Register before async work |
| Pool drains API budget | Eager refill on every connect | Lazy: fills on first use, cron every 6h |
| Always says "good morning" | No time check in greeting | Added hour-based time-of-day detection |
| Ring modulation double voice | Sum/difference frequencies audible | Removed ring mod, use TTS voice settings only |
