### BIOS menu plan (approved, not yet coded)

**Boot flow:**
```
Splash → POST → "Hold screen for BIOS..." (2s countdown)
  ├─ Screen held → BIOS Menu
  │   ├─ Continue Boot
  │   ├─ Audio Test (mic meter, beep, echo, push-to-talk)
  │   ├─ WiFi Scan (networks + signal bars)
  │   ├─ System Info (CPU, RAM, MAC, version)
  │   └─ Setup WiFi (exits to BLE/AP provisioning)

→ BLE provisioning (if no WiFi creds)
→ WiFi connect → face UI
```
