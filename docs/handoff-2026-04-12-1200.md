**Session: Hardware shopping list and physical form planning**

- **Status:** Advisory session — no code changes. Discussed what hardware to buy alongside the MicroSD card and battery Hendra is already sourcing.

- **Decisions:**
  - **BME280 sensor (GY-BME280 3.3V variant):** Approved for purchase (~Rp65.000). Connects to existing I2C bus via JST SH 1.25mm 4-pin header (GND, 3.3V, SDA→GPIO16, SCL→GPIO15). Address 0x76, no conflict. Needs a JST SH 1.25mm 4-pin cable with bare ends for wiring.
  - **Servo plan settled on 2 arms only (SG90, GPIO2 + GPIO3).** Initially considered 3 servos (2 arms + 360° body rotation) but concluded rotation is pointless without spatial awareness — the bot has no camera or directional mic to know where the user is. Expressive arm movement is enough; face animations handle the rest on-screen.
  - **GPIO14 + GPIO21 kept free** for sensors (LDR light sensor, future peripheral).
  - **Physical enclosure:** Hendra is interested in building a form factor like the reference photo (3D-printed body, TFT face, articulated arms, USB-C power). Need to determine 3D printer access.
  - **Servo power note:** SG90s should be powered from a separate 5V supply, not the ESP32's 3.3V pin. GPIO signal at 3.3V is fine. Shared ground required.

- **Shopping list agreed:**
  1. MicroSD card (already ordering)
  2. Battery — 3.7V LiPo, 1000-2000mAh, JST connector (still searching)
  3. GY-BME280 3.3V module
  4. JST SH 1.25mm 4-pin cable (bare ends) for I2C header connection
  5. 2x SG90 micro servos (for arms)
  6. LDR photoresistor + 10kΩ resistor (for auto-brightness on GPIO2 — reconsider pin assignment if GPIO2 goes to servo)

- **Open threads:**
  - GPIO allocation conflict: LDR was suggested on GPIO2, but servo arms also use GPIO2+GPIO3. If both arms + LDR wanted, need to use GPIO14 or GPIO21 for LDR instead.
  - 3D printer access — not yet confirmed. Needed for enclosure.
  - Battery selection still in progress — needs to fit eventual enclosure dimensions.
  - No firmware written yet for BME280 reading, servo control, or LDR. All are new modules.
